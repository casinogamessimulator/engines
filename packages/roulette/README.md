# Roulette engine

Single, double and triple zero wheels, every bet with la partage and en prison, and settlement.

- **Method:** Combinatorial analysis
- **Checked against:** 2.70%, 5.26%, 7.69%, 7.89% (five-number bet), 1.35% (la partage).
- **Used by:** [Roulette on Casino Games Simulator](https://casinogamessimulator.com/roulette/odds/)

Run `pnpm test` here for the checks, and see `scripts/` for the precomputations whose results ship as JSON in `src/`.
